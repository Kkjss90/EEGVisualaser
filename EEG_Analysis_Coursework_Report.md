## 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ (АНАЛИЗ ПРЕДМЕТНОЙ ОБЛАСТИ)

### 2.1. Краткие основы ЭЭГ

#### Что такое ЭЭГ?

Электроэнцефалография (ЭЭГ) - метод исследования электрической активности головного мозга путем регистрации разности потенциалов между электродами, размещенными на поверхности головы. ЭЭГ отражает суммарную активность миллионов нейронов коры головного мозга.

#### Физиологические основы

ЭЭГ-сигналы возникают в результате синхронной активности пирамидальных клеток коры головного мозга. Основные источники активности:

- **Постсинаптические потенциалы** нейронов
- **Синхронизация активности** больших групп нейронов
- **Влияние таламокортикальных связей**

#### Основные ритмы мозга

ЭЭГ-сигналы характеризуются наличием различных частотных ритмов, каждый из которых связан с определенными состояниями мозга:

| Ритм | Частотный диапазон | Характеристика | Физиологическое состояние |
|------|-------------------|---------------|------------------------|
| **Дельта (δ)** | 0.5-4 Гц | Высокая амплитуда, медленные волны | Глубокий сон, кома |
| **Тета (θ)** | 4-8 Гц | Средняя амплитуда | Расслабление, дремота, медитация |
| **Альфа (α)** | 8-13 Гц | Регулярные волны | Спокойное бодрствование, закрытые глаза |
| **Бета (β)** | 13-30 Гц | Низкая амплитуда, быстрые волны | Активное мышление, концентрация |
| **Гамма (γ)** | 30-100 Гц | Очень низкая амплитуда | Высокая когнитивная активность |

### 2.2. Артефакты ЭЭГ и методы их устранения

Артефакты - это нежелательные компоненты сигнала, искажающие истинную ЭЭГ-активность. Основные типы артефактов:

#### Типы артефактов:

1. **Артефакты моргания (ocular artifacts)**:
   - Возникают при движении глазных яблок
   - Частоты: 0.5-4 Гц (дельта-диапазон)
   - Амплитуда: до 100-200 мкВ

2. **Мышечные артефакты (EMG artifacts)**:
   - Связаны с сокращением мышц головы и шеи
   - Частоты: 20-300 Гц
   - Амплитуда: высокая, маскирует ЭЭГ

3. **Артефакты сердцебиения (ECG artifacts)**:
   - Связаны с электрической активностью сердца
   - Частоты: 1-2 Гц (ритм сердца)
   - Амплитуда: 10-50 мкВ

4. **Артефакты движения (movement artifacts)**:
   - Возникают при движении электродов
   - Низкочастотные, высокая амплитуда

#### Методы устранения артефактов:

1. **Фильтрация**: Использование цифровых фильтров для подавления определенных частот
2. **ICA (Independent Component Analysis)**: Разделение сигнала на независимые компоненты
3. **Автоматическая детекция**: Поиск артефактов по амплитуде и статистическим критериям
4. **Ручная разметка**: Визуальный осмотр и удаление артефактных сегментов

### 2.3. Методы обработки сигналов для ЭЭГ

#### Методы фильтрации:

1. **ФНЧ (Low-pass filter)**: Подавляет высокие частоты, сглаживает шум
2. **ФВЧ (High-pass filter)**: Удаляет низкочастотные тренды и дрейф
3. **Полосовые фильтры (Band-pass)**: Выделяют определенный частотный диапазон
4. **Режекторные фильтры (Notch)**: Подавляют узкие полосы частот (например, 50 Гц - сеть)

#### Спектральный анализ:

1. **Быстрое преобразование Фурье (FFT)**: Разложение сигнала на частотные компоненты
2. **Метод Уэлча**: Оценивание спектральной плотности мощности с использованием окон
3. **Вейвлет-преобразование**: Анализ в частотно-временной области

#### Методы выделения признаков:

1. **Статистические признаки**: Среднее, дисперсия, асимметрия, эксцесс
2. **Частотные признаки**: Мощность в различных ритмах, пиковые частоты
3. **Нелинейные признаки**: Энтропия, фрактальная размерность
4. **Временные признаки**: Амплитуда, частота спайков
